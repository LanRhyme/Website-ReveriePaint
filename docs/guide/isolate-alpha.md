# 单图层孤立与 Alpha 锁定

在精细刻画细节或检查线稿闭合度时，图层孤立与透明度锁定是画师最高频的得力工具

## 单图层孤立显示（Isolate Layer）

当工程内包含数十个甚至上百个图层时，查找某一个部件或排查杂线非常繁琐：

- **长按眼睛触发孤立**：长按目标图层卡片上的「眼睛（可见性）」图标约 300ms，系统将立即独占显示该图层，并临时隐藏其余所有图层
- **再次长按恢复全局**：再次长按该图层的眼睛图标，所有图层的原始可见性状态将精准还原，无需手动逐一开启
- **检查底色与溢色**：孤立模式配合纯色背景可快速发现暗部死角的未填色白点与边缘溢色

## Alpha 锁定（锁定透明度）

- **工作原理**：开启后，该图层所有透明像素的 Alpha 通道被完全写保护，后续所有笔触、橡皮擦或油漆桶涂抹均只能作用在已有像素的区域内
- **典型应用场景**：
  - **二分阴影与高光刻画**：在线稿底色平涂完成后开启 Alpha 锁定，选用较暗色调沿形体直接铺设阴影，线条边缘完全贴合底色轮廓
  - **线稿局部变色**：在纯黑线稿图层开启 Alpha 锁定后，使用大画笔涂抹深红或深棕色，快速实现彩色线稿效果
