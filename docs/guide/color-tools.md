# 色彩面板与 3D 光影球

ReveriePaint 配备专业色彩工作台，整合了色相环、调色板预设与创新的 3D 光影辅助参考球

## 色彩模型与拾色面板

- **外环色相环（Hue Ring）**：外环精准旋转选择光谱色相，内框采用 HSV 饱和度/明度双轴矩形，支持微距精细调节
- **色调与调和比对**：支持互补色、三分色、类似色等色彩调和线段辅助标记，为插画配色建立严谨色彩关系
- **最近使用历史色**：底栏常驻显示最近采样的 16 组历史色阶槽位，点击即可秒级切回
- **专业色板导入导出**：支持导入标准 Adobe `.aco` / `.ase` 色板以及 GIMP 色板预设，支持一键将当前画作提取为主色调卡并分享导出

## 3D 光影参考球（Lighting Sphere）

针对初学者与原画师在铺设光影时容易迷失主光源角度与体积明暗交界线的痛点，系统内置了实时 3D 光影球浮窗：

- **主光源方向自由旋转**：在光影球上滑动拖拽，可实时调整虚拟主光源照射的角度与高低俯仰
- **多光源与环境光调和**：支持叠加第二冷暖补光光源，并可独立调节全局环境散射光比例
- **实时明暗交界线参考**：直观显现球体的高光点、明暗交界线（Terminator）、反光区与投影区分布，指导头部素描明暗走势
- **一键采样球体光色**：长按光影球表面任一明暗受光区域，即可直接吸取对应物理光影色阶作为画笔前景色
