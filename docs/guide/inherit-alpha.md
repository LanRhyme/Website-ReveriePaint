# 继承不透明度实战

ReveriePaint 继承了 Krita 工业级的「继承不透明度（Inherit Alpha）」机制，这也是数字绘画中剪贴蒙版（Clipping Mask）的高阶实现形式

## 核心机制与原理

与传统画图软件只向上方单图层绑定的剪贴蒙版不同，继承不透明度的裁剪基准为：**同图层组内下方所有图层像素的可见性并集**

::: tip 关键设计：图层组隔离
开启「继承不透明度」的图层必须位于一个「图层组（Group）」中：
- 若直接放在根目录，该图层会向下穿透继承背景层或全局底层，导致无法被裁切
- 放入独立图层组后，裁剪边界被严格限制在该组内部，组外的图层不受任何影响
:::

## 经典三层结构实战

在绘制角色立绘时，标准的图层组织示范：

```text
[组] 角色上色组（Group）
  ├── [图层] 图层 3：高光反射（开启「继承不透明度」+ 叠加模式）
  ├── [图层] 图层 2：赛璐璐阴影（开启「继承不透明度」+ 正片叠底）
  └── [图层] 图层 1：固有底色（不开启继承，铺设人物色块）
```

- **图层 1** 作为基底，绘制角色完整的固有色平涂轮廓
- **图层 2 与图层 3** 开启 `α` 图标（继承不透明度），下笔时可以随意涂画，多余笔画会被底层轮廓自动裁剪，绝不会溢出到画布空白区域
- 当需要修改基底形状时，只需在图层 1 上用橡皮擦擦除，上方所有阴影与高光均会实时联动收缩
