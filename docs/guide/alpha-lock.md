# Alpha 锁定与图层孤立

两个「只关注一层」的开关：一个限制你只能画在已有像素里，一个让你只看这一层。

## Alpha 锁定（锁定透明度）

在图层面板卡片左滑，或 `图层设置` 里打开 **Alpha 锁定 / 锁定透明度**。

开启后该层的透明像素被写保护：所有笔触、橡皮、油漆桶、滤镜都只能作用于**已有的不透明区域**。

### 典型用法

- **二分阴影**：底色平涂完成后开 Alpha 锁定，直接用大笔刷压暗部，边缘自动贴合轮廓
- **线稿变色**：线稿层开锁定，用大笔刷整片刷深红/深棕，得到彩色线稿
- **局部调色**：锁定后叠一层低不透明度颜色「透」出来，不会渗到画布空白处

::: tip 和剪贴蒙版的区别
Alpha 锁定是本层自锁，不需要别的图层；剪贴蒙版是借下一层的形状。两者可以同时开 —— 锁定负责「不涂出本层」，剪贴负责「不涂出基底」。
:::

## 图层孤立

图层多到看不清某一部分时用：

- **长按眼睛图标**（约 300ms）：只显示这一层，其余临时隐藏
- **再次长按**：恢复之前的可见性组合，不用逐个手动打开
- 面板行上会显示孤立状态标记，避免忘了自己正处在孤立模式

适合检查：线稿是否闭合、底色有没有漏涂、阴影边缘是否溢色。配合纯色背景更容易看出白点与脏边。

## 透明度蒙版

需要非破坏性地局部透明时，用**透明蒙版**而不是橡皮：

- `图层设置 → 添加蒙版 → 透明蒙版`
- 蒙版上黑色 = 透明，白色 = 保留，灰色 = 半透明
- 蒙版可反转、可单独显示、可应用（合并进图层像素）
- 删除蒙版即可完整还原，橡皮做不到这一点

做渐变淡出、局部虚化边缘、不规则擦除时优先用蒙版。
