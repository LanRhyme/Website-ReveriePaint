# 图层体系与混合模式

ReveriePaint 的图层架构基于 Krita 核心图层树，支持无限层级嵌套分组与丰富的混合模式

![图层面板与图层组](/docs/doc-layers-presets.webp)

## 图层类型与管理

- **绘图图层（Paint Layer）**：标准栅格像素图层，支持任意笔刷上色、橡皮擦除与滤镜效果
- **图层组（Group Layer）**：支持将多个相关图层归拢收纳，组内支持独立设置不透明度与混合模式，点击箭头折叠展开
- **图层混合模式**：提供 20 余种行业通用混合模式，分为四大类：
  - **基础与减暗类**：正常（Normal）、正片叠底（Multiply）、变暗（Darken）、颜色加深（Color Burn）
  - **加亮与发光类**：滤色（Screen）、变亮（Lighten）、颜色减淡（Color Dodge）、添加 / 线性减淡（Add）
  - **对比与融合类**：叠加（Overlay）、柔光（Soft Light）、强光（Hard Light）、鲜艳光（Vivid Light）
  - **色彩与分量类**：色相（Hue）、饱和度（Saturation）、颜色（Color）、明度（Luminosity）

## 图层操作手势

- **左右滑动动作条**：在图层卡片上轻扫可快速呼出复制、锁定、清空与删除快捷按钮
- **长按拖拽重排**：长按图层卡片触发震动反馈后上下拖动调整层级顺序，拖入组标题即可快速归入组内
- **双击重命名**：双击图层名称文本框弹出键盘修改图层名字
