# 图层体系与混合模式

图层树直接继承自 Krita：分组可以无限嵌套，混合模式、不透明度、蒙版都按 Krita 的语义工作。

![图层面板](/docs/doc-layers-panel.webp)

## 两种图层面板

绘画页有两个入口，内容一致、用途不同：

| 面板 | 位置 | 适合 |
| :--- | :--- | :--- |
| **快捷图层面板** | 画布右下角浮动小卡 | 快速切层、开关眼睛、拖拽排序 |
| **完整图层面板** | 右上角展开的面板 | 完整图层树、颜色标签、类型菜单、蒙版操作 |

完整面板顶部一排图标：`＋` 新建颜料层、📁 新建图层组、图层图标（图层类型菜单）、对齐/排序类操作、更多；右侧是面板收起与关闭。图层类型菜单里可以新建**填充图层 / 滤镜图层 / 描边图层 / 新建 3D 参考图层**，也能在「蒙版」分组里添加透明度蒙版与局部选区蒙版，或用「盖印可见图层」把当前合成结果压成一层。

![完整图层面板](/docs/doc-layers-full.webp)

两种面板的图层行都从下往上对应画面从前到后：

- **眼睛**：可见性；长按眼睛进入[图层孤立](/guide/alpha-lock#图层孤立)
- **缩略图**：内容预览，随笔画实时刷新
- **名称**：双击重命名
- **α 图标**：继承透明度 / 剪贴蒙版的开关（可在设置里决定顶部快捷按钮是哪一个）
- **卡片左滑**：呼出复制、锁定、清空、删除快捷按钮（快捷面板）
- **长按拖拽**：调整层级顺序，拖到组标题上即可放入组内

面板顶栏：`＋` 新建图层、`⋮` 更多（添加图层组 / 剪贴蒙版 / 继承透明度 / 图层设置）、`⟷` 折叠面板、`✕` 关闭。

![图层操作菜单](/docs/doc-layers-menu.webp)

## 图层类型

| 类型 | 说明 | 典型用途 |
| :--- | :--- | :--- |
| **颜料层（Paint）** | 普通栅格像素层，可任意绘制 | 线稿、上色、背景 |
| **图层组（Group）** | 收纳子图层，自身可设不透明度与混合模式 | 把「角色」「背景」分开管理 |
| **填充层（Fill）** | 整层纯色或图案，改色即时生效、不吃笔画 | 底色、氛围色、快速试配色 |
| **描边层（Stroke）** | 把图层像素按设定描边（内/外/居中） | 贴纸感线稿、字体描边、贴图外轮廓 |
| **调整层（Adjustment）** | 非破坏性调色（亮度对比、色相、曲线等） | 整体调色，随时改参数 |
| **克隆层（Clone）** | 引用另一图层的像素 | 同素材复用、暂存中间结果 |
| **透明蒙版（Transparency Mask）** | 挂在图层上的灰度蒙版，黑色透明、白色保留 | 局部淡出、渐变过渡、不规则擦除 |

图层面板的「＋」默认新建颜料层；其他类型在 `⋮ → 添加图层组`、`图层设置` 或工具面板里创建。

::: tip 填充层 vs 油漆桶
**填充层**是整层纯色（或图案），改颜色不会破坏上面的笔画，适合随时试配色；**油漆桶**是把颜色画进当前颜料层，属于像素操作。底色调色阶段优先用填充层。
:::

## 混合模式

20 余种，按用途分四组：

| 组 | 模式 |
| :--- | :--- |
| **基础与减暗** | 正常、正片叠底、变暗、颜色加深 |
| **加亮与发光** | 滤色、变亮、颜色减淡、添加/线性减淡 |
| **对比与融合** | 叠加、柔光、强光、鲜艳光 |
| **色彩与分量** | 色相、饱和度、颜色、明度 |

设置位置：图层卡片右滑 → `图层设置`，或面板 `⋮ → 图层设置`。组图层同样有混合模式，会整体作用于组内合成结果。

常用组合：

- **正片叠底**：阴影、加深线稿
- **滤色 / 添加**：高光、发光、光斑
- **叠加 / 柔光**：整体氛围、质感叠加
- **颜色 / 明度**：改色调不改明暗关系

## 图层组

- 组内图层的混合模式先在组内合成，再按组自身的不透明度与混合模式参与整体
- **穿透（Pass Through）**：组可设为穿透模式，子图层直接与组外内容混合（类似 Photoshop 的「穿透」），做色彩调整组时特别有用
- 组的折叠箭头可收起子层，嵌套层数不限但建议控制在三层以内，面板会更好用

## 图层操作与撤销

| 操作 | 入口 |
| :--- | :--- |
| 新建 / 删除 / 复制 | 面板顶栏 `＋`、卡片左滑、顶栏的复制与删除按钮 |
| 上下移动、移入移出组 | 长按拖拽，或 `图层设置` 里的移动项 |
| 向下合并、合并可见、栅格化 | `图层设置` |
| 添加蒙版 / 移除蒙版 / 反转蒙版 / 应用蒙版 | `图层设置` |
| 颜色标签 | 图层设置里选色标，便于分组识别 |

所有图层操作（增删、移动、合并、蒙版、改名、显隐）都进撤销栈，一次撤销回退一步；合并类操作会打包为单步。
