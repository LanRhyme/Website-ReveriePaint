# 色彩与取色

色彩面板整合了色相环、调色板、色彩调和与 3D 光影球 —— 取色、配色、判断明暗关系都在同一个浮窗里完成。

![色彩面板](/docs/doc-color-wheel.webp)

## 面板构成

| 页签 | 内容 |
| :--- | :--- |
| **色轮** | 外环色相环 + 内部 HSV 饱和度/明度矩形，附 H/S/V 数值滑杆 |
| **色卡** | 预设与自定义调色板：基本色、莫兰迪、图片色卡等，可新建色卡、加色块 |
| **滑块** | RGB / HSV / CMYK 全通道滑杆 + 十六进制输入，可复制 / 粘贴色值 |

面板底部的「记忆色」记录最近用过的颜色（含「统统扫光」清空），点一下即可切回。
底部常驻最近使用的历史色，点一下即可切回。

## 取色

- **画笔取色**：切到吸管工具后点画布任意位置
- **长按吸色**：单指长按画布约 300ms 呼出双环取色盘 —— 外环是最新采样色，内环是画笔原色；拖动可连续采样
  - 灵敏度、取色点偏移（避免手指遮挡）、笔模式下是否允许手写笔长按，都在 设置 → 手写笔 → 长按画布吸色
- **从参考窗口取色**：参考窗口里的图片同样可以吸色
- **前后景互换**：工具面板上的双向箭头，或键盘 `X`

## 调色板与色板文件

- 支持导入 Adobe `.aco` / `.ase` 与 GIMP 色板
- 可把当前画作的主色提取成色卡，导出分享
- 自定义调色板随工程保存，切换工程不会串色

## 3D 光影参考球

画光影时最容易迷路的是**主光方向**与**明暗交界线位置**，光影球把这两件事可视化：

- **拖拽球体**改主光角度与俯仰
- **叠加第二补光**（冷暖对比），并调环境光比例
- 球面实时显示高光点、明暗交界线、反光区、投影区
- **长按球面**可直接吸取该处的光色作为前景色

::: tip 用法
先在光影球上把光源摆到与画面一致的方向，记住交界线的位置；再回到画布按分区上色。它只是参考，不会影响你的画布内容。
:::
