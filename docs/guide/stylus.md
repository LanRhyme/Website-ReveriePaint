# 多品牌手写笔与压感声学

ReveriePaint 具备底层硬件级手写笔协议适配层，覆盖主流安卓平板与主动式手写笔方案

## 适配设备阵列

- **Wacom EMR 无源电磁笔方案**：三星 Galaxy Tab S 系列（S-Pen）、联想小新 Pad Pro / YOGA 电磁笔，拥有原生零延迟与悬停光标检测
- **品牌主动式电容触控笔**：小米灵感触控笔（Xiaomi Focus Pen）、华为 M-Pencil（需关闭鸿蒙侧边截屏助手）、荣耀 Magic-Pencil、OPPO Pencil 与 vivo Pencil
- **外接专业数位板与手绘屏**：通过 USB-OTG 或蓝牙直连的高漫（Gaomon）、绘王（Huion）、Wacom One / Intuos 系列数位板，全功能支持倾斜角与侧键映射

## 贝塞尔压感曲线调校

在「设置 ＞ 手写笔」中提供基于三次贝塞尔样条的全局压力映射编辑器：

- **线性（Linear）**：输入物理压力与输出笔刷线宽、浓度保持 1:1 真实映射
- **轻柔（Soft）**：轻触即可达到饱满墨色，适合手劲较轻、喜欢轻快排线的画师
- **硬实（Hard）**：需用力按压才能释放最大画笔尺寸，适合精雕细刻与控制粗细微差
- **S 形对比（S-Curve）**：两端平缓、中段陡峭灵敏，增强下笔轻重笔触的反差张力

## 纸感微震与声学引擎（PaperSoundEngine）

通过实时捕获下笔即时速度、压力变化率与加速度矢量，在设备扬声器与线性马达上拟真合成真实的纸笔物理摩擦反馈：

- **铅笔纸质（Pencil）**：微粒摩擦声效，低速排线细腻柔和，高速运笔清脆沙沙作响
- **钢笔墨水（Ink）**：顺滑深沉的湿墨流动阻尼声效
- **机械轻嗒（Tick）**：富有段落节奏感的微触觉确认音
- **动态低通滤波**：声学合成器依据运笔速度动态开放截止频率，还原在素描纸上绘制的沉浸体验
