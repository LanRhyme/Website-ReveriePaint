# 笔刷工坊与 ABR 导入

ReveriePaint 支持导入行业主流画笔规范，并提供深度参数定制与画笔资源包打包分发能力

![画笔面板导入入口](/docs/doc-brush-import.webp)

## 笔刷格式支持与一键导入

- **系统分享导入（首选）**：在 QQ、微信、网盘或文件管理器中直接点击笔刷文件，选择「用其他应用打开」或「分享」，点选 **ReveriePaint** 即可秒级导入
- **Krita 原生预设**：直接导入单个 `.kpp` 笔刷预设与包含完整笔尖图案的 `.bundle` 资源包
- **Photoshop ABR 格式深度支持**：
  - 支持直接加载 Photoshop v7~v10 规格的标准 `.abr` 笔刷合集包
  - 引擎底层自动解析多组采样光栅印章并提取无损笔尖
  - 自动补全 Krita 规格的压力曲线与流控 XML 描述符，无需电脑端转换即可在平板直接使用
- **MyPaint 引擎笔刷**：完整解析并兼容加载 `.myb` 格式笔刷定义
- **整组笔刷打包导出**：可将自定义调校的多支画笔或自带笔尖纹理的预设一键导出为通用 `.bundle` 资源包，便于在画师圈子分发

![QQ 接收文件打开方式](/docs/doc-brush-qq.webp)

## 笔刷工坊调校维度

点击笔刷面板右上角微调滑块即可进入全功能笔刷工坊：

| 调校模块 | 参数配置项 | 说明与应用 |
| :--- | :--- | :--- |
| **笔尖与遮罩** | 尺寸、圆度、角度、间距（Spacing） | 支持多图样循环随机抖动采样 |
| **动力学映射** | 速度感应、压力映射、流量（Flow） | 将物理下笔行为映射至颜色浓度与散布 |
| **混色与涂抹** | 取色率（Color Rate）、涂抹强度（Smudge） | 模拟传统水彩与厚涂油画的颜料物理混合 |
| **几何与空间** | 笔画方向跟随、倾斜角（Tilt）、方位角（Azimuth） | 还原扁平马克笔与侧峰削角排线效果 |
| **材质与纸纹** | 纹理贴图叠加、对比度、镂空阈值 | 还原水彩纸微凸粗糙质感与干燥飞白 |

## 运笔抖动修正与平滑算法

在笔刷工坊「平滑」页签中提供多级平滑模式：

- **无平滑（Raw）**：输出手写笔最原始的毫秒级高频物理采样，零滤波延迟，适合高速速写
- **基本平滑（Basic）**：轻微平滑过滤手指微颤，维持高跟手度
- **加权平均（Weighted）**：通过前置多点加权平均滤波消除折线感，适合中速排线
- **稳定器（Stabilizer）**：引入带延迟拖拽半径的阻尼虚拟光标，运笔有清晰的牵引线感，专为高精度勾线与完美闭合线稿打造
