# 流动蚂蚁线选区与液化形变

ReveriePaint 搭载重构的硬件加速选区着色体系与微秒级响应的高性能液化变形引擎

## 选区系统与动态流动视觉

- **选区类型**：自由手绘套索、几何矩形/椭圆、多边形连线以及魔棒连续容差选取
- **动态流动蚂蚁线（Marching Ants）**：采用硬件 GPU 着色器实时渲染动态行进虚线边界，即便在高密度复杂的发丝与微小选区边缘也清晰可辨
- **低对比度斑马斜纹（Zebra Stripes）**：选区外部区域采用低对比度、半透明的优雅斜纹遮罩覆盖，既能明确区分未选区域，又不会干扰画师对画面原有色彩冷暖与明度的观察
- **布尔运算状态机**：
  - **新建模式**：每次圈选重置建立独立选区
  - **添加模式（+）**：与已有选区无缝合并
  - **减去模式（-）**：从已有选区中精确镂空
  - **相交模式（∩）**：仅保留重叠区域并剔除孤立碎片
- **选区悬浮快捷动作条**：圈选完成后在屏幕边缘自动展开快捷操作栏：
  - **反选与羽化**：一键倒置选区或进行 1~128px 边缘柔和渐变过渡
  - **像素级收缩与扩展**：精准扩充或缩窄 1~32px 边界
  - **提取与克隆**：一键执行「剪切到新图层」、「复制到新图层」或「清空内容」
- **ARM NEON 预乘 Alpha 边缘去白边**：通过 ARM64 NEON 矢量加速优化抗锯齿采样边界，消除选区浮动变换或粘贴时半透明边缘产生的泛光白边

## 自由变换（Transform）

- **标准八点手柄**：支持自由拉伸、按住等比锁定缩放、中心锚点自由位移与全向旋转
- **极速镜像**：一键水平镜像翻转或垂直翻转当前选区图像
- **透视与自由扭曲**：支持四角自由拖拽透视倾斜以及网格贝塞尔形变

## 高性能液化变形工具（Liquify）

提供 5 种基于高精度抗锯齿形变网格的推拉扭曲工具：

| 形变模式 | 作用方式 | 典型用途 |
| :--- | :--- | :--- |
| **推移（Push）** | 顺应笔触拖拽方向推挤像素 | 调整五官轮廓比例、修改人体曲线骨骼 |
| **膨胀（Bloat）** | 以笔刷中心为圆心向外辐射放大 | 放大瞳孔、增加高光体积感 |
| **收缩（Pucker）** | 以笔刷中心为圆心向内聚拢变小 | 收窄下巴、缩小鼻翼细节 |
| **顺时针旋转（Rotate CW）** | 围绕笔尖顺时针扭曲漩涡 | 调整衣褶卷曲、发梢旋转 |
| **逆时针旋转（Rotate CCW）** | 围绕笔尖逆时针扭曲漩涡 | 调整反向动态弧线 |

- **沿路径自适应补点**：高频触摸事件沿拖拽路径自适应细分插值，消除高速推拉造成的笔迹断口与折角
- **严格约束活动选区**：液化变形被严格约束在活动选区之内，选区外像素绝对固定不被拉扯
- **图层 Alpha 锁定保护**：开启 Alpha 锁定的图层仅改变颜色通道像素位置，轮廓边缘与透明度严禁外扩
