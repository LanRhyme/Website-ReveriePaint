# 画笔与压感

画笔面板管「选哪支笔、这支笔多粗多淡」；笔尖形状、动态曲线、纹理这些更深的东西在 [笔刷工坊](/guide/brush-studio)。这一页只讲日常作画真正会调的参数。

## 打开笔刷设置

- 左侧工具栏点**画笔**工具，右侧弹出笔刷设置面板（大小 / 不透明度 / 流量 / 混合模式 / 间距 / 比例 / 柔化 / 角度）
- 面板右上「高级工坊」进入笔刷工坊，调笔尖形状与动态

![笔刷设置面板](/docs/doc-brush-settings.webp)

笔刷卡片：单击选中，长按卡片右下角进入**笔刷工坊**。面板右上是分类筛选（铅笔、墨水、水彩、混合、橡皮、像素、纹理、形状等）。

### 收藏与整理

- 长按卡片唤出多选，可批量移动到自定义分组、批量删除或导出成 `.bundle` 分享
- 自定义分组支持重命名、排序、整组导出；内置分类不可删，删组时内置笔刷会自动回到「全部」
- 常用笔刷建议放进「常用」，笔刷条只显示这里的内容，切笔不用翻列表

## 日常五个参数

打开笔刷工坊的「核心基础」页，或直接用顶栏两个圆形滑块调前两项：

| 参数 | 作用 | 常见用法 |
| :--- | :--- | :--- |
| **大小** | 笔尖直径（像素） | 打形用小笔、铺色用大笔；`[` `]` 快速增减 |
| **不透明度** | 单次落笔的最大浓度 | 线稿 100%，铺色 60~80%，叠色 30% |
| **流量** | 同一笔内重复叠涂的累积速度 | 低流量 + 多涂几遍 = 自然的渐变过渡 |
| **间距** | 相邻笔尖印迹的间隔（占直径的百分比） | 小间距实线、大间距虚线/颗粒；散布类笔刷常配大间距 |
| **柔化** | 笔尖边缘硬度 | 100% 为原样硬边，数值越低越柔（喷枪/柔光） |

::: tip 不透明度 vs 流量
- **不透明度**决定这一笔最多能压多深，一笔画过去不会因为慢而变深
- **流量**决定同一笔里反复经过时的叠加速度，想把颜色「揉」开就压低流量

两者都低时最容易画出「怎么涂都不上色」的假象，先确认不是在用低不透明度笔刷叠在浅色上。
:::

工坊「笔尖几何」页还有角度、圆度比例、角度抖动；「动态表现」页有散布、笔尾收尖、防抖平滑度、喷枪流速。这些是笔刷本身的设定，一般调好一次就固定下来。

## 抖动修正与平滑

手抖明显时用这里，位置：设置 → 手写笔 → 抖动修正（高级）。

| 选项 | 说明 |
| :--- | :--- |
| 平滑算法 | **关闭** / **基础平滑** / **加权平滑（Krita）**，后者最接近桌面 Krita 手感 |
| 平滑距离 | 最小/最大距离，可锁定；数值越大线越稳、跟手延迟越明显 |
| 随画布缩放自适应 | 平滑距离按画布缩放换算像素，放大作画时不会突然变迟钝 |
| 平滑压感 | 对落笔压感做高斯平滑，消除轻压时的跳变 |
| 笔尾敏锐度 | 抬笔时加速收束，减轻长距离平滑带来的拖尾 |

::: warning 平滑不是越高越好
平滑距离拉满会明显拖慢起笔响应，画快速长线时容易「甩尾」。日常建议「加权平滑 + 中等距离」，需要极稳的长线时再临时调高。
:::

## 快捷滑块与笔刷上限

- **快捷滑块**：常驻在画布边缘，默认控制大小与不透明度；可在设置里改成流量、换成单滑块、调整滑块长度
- **笔刷上限跟随画布**：开启后笔刷最大尺寸自动设为画布长边的 1/2，避免大画布上笔刷「不够大」
- **笔刷光标**：可设为准星、圆环或系统光标，笔模式下还能单独设「轮廓反映实际大小」—— 圆环随压感实时缩放

## 常见手感问题

| 现象 | 先查这里 |
| :--- | :--- |
| 笔画很淡、怎么叠都不深 | 不透明度/流量是否偏低；笔刷是否选了「橡皮」或混合类 |
| 线条发虚、边缘毛糙 | 笔尖柔化是否过低、间距是否过大；换一支硬边笔试试 |
| 落笔延迟明显 | 渲染调度选「极速响应」；平滑距离过大；大画布 + 多图层也会增加首笔延迟 |
| 压感没反应 | 手写笔页面确认压感曲线未归零、笔模式是否拦截了信号 |
| 换笔后参数全变 | 正常：每支笔各自记参数。想统一请用笔刷工坊的「保存为预设」 |
