# 常见问题

## 安装与启动

**装不上 / 解析包错误**

架构包不匹配最常见：绝大多数设备装 `arm64-v8a`，只有 32 位老设备才用 `armeabi-v7a`。另外确认系统版本 ≥ Android 7.0。

**打开就闪退**

1. 先确认不是覆盖安装损坏：卸载后重装（工程在应用私有目录，卸载会丢，重要作品先备份）
2. 仍闪退请在 [Issues](https://github.com/LanRhyme/ReveriePaint/issues) 反馈，附上 `设置 → 导出日志` 复制的内容

**HarmonyOS NEXT 能用吗**

纯血鸿蒙不再兼容 AOSP 图形栈，**不保证可用**；HarmonyOS 4.x 及以下的兼容模式不受影响。

## 绘画手感

**笔画跟不上手 / 有延迟**

设置 → 历史记录与性能 → 渲染调度改「极速响应」；同时检查抖动修正的平滑距离是否过大、画布是否过大、是否有多个 3D 参考图层。

**笔压没反应**

- 设置 → 手写笔，确认压感曲线没有归零
- 笔模式下确认允许手写笔取色（吸色相关）
- 第三方笔需要系统本身识别为手写笔（部分蓝牙笔只在特定 App 里启用压感）

**线条抖**

打开抖动修正（设置 → 手写笔 → 抖动修正 → 高级），选「加权平滑（Krita）」，平滑距离取中等；需要极稳长线时再临时拉高。

**手指一碰就画，想用手势**

开启「仅手写笔模式」：设置 → 手写笔 → 笔模式。

## 图层

**剪贴蒙版不生效**

剪贴找的是**紧邻的下一个图层**。中间隔了空图层、隐藏图层，或基底本身是空的，都会失效。

**继承透明度没反应**

它必须放在**图层组内**。直接放根目录会裁到整张画布，看起来像没生效。详见 [剪贴蒙版与继承透明度](/guide/clipping)。

**图层上限是多少**

不写死，按设备可用内存 × 画布尺寸动态计算。画布越大、单层像素越多，能开的层越少。

**改了颜色但整个组都变了**

检查是不是改到了组图层的混合模式或不透明度，或者组开了「穿透」直接和组外混合。

## 工程与保存

**退出没保存，能找回吗**

能。画画时默认有自动保存与快照：画廊首页会提示「未保存草稿」；也可以在 设置 → 通用设置 → **最近自动保存快照** 里挑一个版本恢复。

**`.revp` 和 `.kra` 怎么选**

- `.revp`：ReveriePaint 原生，信息最全（含作画耗时、回放数据）
- `.kra`：Krita 原生，方便和桌面 Krita 互通
- 两者都能保留图层结构；给 PS 用请导出 PSD

**WebDAV 同步冲突怎么办**

同一工程在两台设备上同时改会产生两个版本，同步时按修改时间保留新的一份，旧版本会进备份目录。跨设备接力前先手动同步一次。

## 导出

**导出很慢**

大画布、多图层、高质量 JPEG 都是主因。先降分辨率，或改用 PNG。

**PSD 打开后偏色**

PSD 色彩管理信息有限，非 sRGB 画布在 PS 里可能按自身默认配置解读。对颜色敏感时交付 PNG/TIFF。

**GIF 有色带 / MP4 没透明**

GIF 只有 256 色；MP4 视频编码不支持 alpha。需要透明用 GIF/ZIP，需要画质用 MP4。

**回放导出提示无数据**

回放数据只对开启录制后的作画生成，早期作品或还没落笔的新画布没有。

## 怎么反馈问题

反馈时附上这三样，定位速度会快很多：

1. **复现步骤**（点哪里、画什么、第几步出问题）
2. **设备与版本**：机型、Android 版本、应用版本（设置 → 关于）
3. **日志**：应用内 设置 → 导出日志（复制到剪贴板），或 `adb logcat` 片段

去 [GitHub Issues](https://github.com/LanRhyme/ReveriePaint/issues/new/choose) 提交，或加入创作者群交流（见 [问题反馈与创作者群](/guide/community)）。
