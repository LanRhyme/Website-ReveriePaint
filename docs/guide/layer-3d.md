# 3D 参考图层

3D 参考图层是一层**不会脏手的立体辅助**：在图层里摆好人体、头部或猫的姿势与打光，照着描线、对透视；需要成稿时再把当前视角烘焙成普通像素层。

![3D 参考图层](/docs/doc-3d-layer.webp)

## 新建

完整图层面板（右上角）顶部的**图层类型**菜单里选「新建 3D 参考图层」，弹出模型库。快捷图层面板没有这个入口。

| 模型 | 内容 |
| :--- | :--- |
| 人体标准素模（男 / 女） | Blender Studio CC0 资产，写实肌肉与骨骼结构 |
| 全身人偶（站姿 / 坐姿） | 八头身比例、结构体块，适合快速定构图 |
| Asaro 头部切面素模 | 经典头部空间折面，打光与结构练习 |
| 3D 写实家猫 | 精细拓扑与四足骨骼，含立耳、胡须、尾巴 |
| 透视方块 / 球体 / 圆柱体 | 空间体块、漫反射与大透视推敲 |
| 导入模型 | `.glb` / `.vrm` / `.pmx` / `.obj` |

![选择 3D 参考模型](/docs/doc-3d-picker.webp)

模型来源是 Blender Studio 人体资产包与社区 CC0 资源，许可写在 `assets/3d_models/CREDITS.md`。

## 摆姿势之前：三种渲染风格

| 风格 | 用途 |
| :--- | :--- |
| **石膏素模** | 只看结构关系，最接近雕塑素描 |
| **光影切面** | 明暗交界与块面切割清晰，适合练光影分区 |
| **结构线框** | 只看布线、透视与体积走向 |

## 视口操作

浮动小工具条（贴着画布边缘，可拖动）：

| 模式 | 操作 |
| :--- | :--- |
| **旋转视角** | 拖动旋转模型，双指可缩放 |
| **平移位置** | 拖动画布内模型位置，对准构图 |
| **调整打光** | 拖动改变主光方向，看不同光照下的体块 |
| **复位视角** | 回到默认机位 |
| 放大 / 缩小 / 重置缩放 | 单独控制模型在画布中的显示大小 |

视口操作只改**参考层的呈现**，不动画布像素，也不算进撤销栈。

## 姿态与骨骼

工具条的「姿态与骨骼」面板分成四块：

### 快速姿态预设

- **人体**：站立立绘、日常坐姿、动感战斗、双手抱胸、自信叉腰、单膝着地
- **猫**：站立机警、乖巧端坐、农民揣、行走迈步、蜷缩入睡、伏击准备、立身伸爪、回首张望、伸懒腰

点一下即切换到对应姿势，切换前会保留当前姿态到撤销栈（`撤销姿态 / 恢复姿态`）。

### 骨骼触控调节

进入「骨骼触控调节」模式后，**直接点画布上的关节**即可选中，拖动即可旋转该关节。选中的骨骼会高亮，面板里可单独「重置此骨骼」。

### 关节微调（轴向滑块）

选中关节后，用滑块按轴精调，比拖动更可控：

- 俯仰（Pitch）/ 偏转（Yaw）/ 翻滚（Roll）
- 人体：头部、脊椎、左右大臂、左右肘、左右大腿、左右膝
- 猫：抬头低头、转头、脊背弓屈、蜷缩、四肢屈伸、尾巴翘起与摆动
- 顶部可按**部位筛选**：全部 / 头部 / 躯干 / 前肢 / 后肢 / 手臂 / 腿 / 尾巴
- 另有「整体升降（贴地微调）」处理模型与画布的对齐

微调是**重绑骨骼**而不是拉网格：骨骼动了，网格保持原有体积与形变质量，不会拉成橡皮泥。

## 从参考到成稿

- **提取线稿**：把当前视角的轮廓提取为新图层，直接在它上面清线
- **栅格化图层**：把当前视角与光影烘焙成普通像素层，之后可以继续画、也能用滤镜

![3D 工具的更多菜单](/docs/doc-3d-menu.webp)
- 栅格化后不可再旋转模型或改骨骼，需要保留可调性时先复制一份再栅格化

## 使用建议与注意

- 3D 层参与图层合成与导出，也和普通层一样有可见性、不透明度与混合模式
- 参考层适合定姿势和透视，**不要直接描素模的明暗交界**：切面是按模型拓扑切出来的，不一定符合你要的光源
- 3D 层实时渲染有开销，工程里放两三层还能接受；定稿后建议栅格化或隐藏
- 保存时 3D 层的模型、姿势、关节偏移、打光方向都会写进 `.revp`，重新打开会恢复
- 导出的 PSD / KRA 里 3D 层按当前视角的合成结果参与，不会带上可编辑的 3D 数据
