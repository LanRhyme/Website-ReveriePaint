# 安装与第一次作画

这一页走完从下载到保存的全流程。已经装好并想了解界面，直接去 [界面导览](/guide/interface)。

## 系统要求

| 项 | 建议 |
| :--- | :--- |
| Android 版本 | 7.0（API 24）及以上 |
| CPU 架构 | 优先 `arm64-v8a`；32 位老设备用 `armeabi-v7a` |
| 运行内存 | 4GB 起可正常作画，8GB 以上适合大画布多图层 |
| 存储 | 单个 `.revp` 工程含内嵌缩略图与回放数据，留足空间 |

::: warning 关于 HarmonyOS NEXT
纯血鸿蒙（HarmonyOS NEXT）不再提供 AOSP 兼容层，图形驱动与动态库都受限，**不能保证可用**。标准 Android 设备（含鸿蒙 4.x 及以下的兼容模式）不受影响。
:::

## 获取安装包

官方渠道两个，内容一致：

- [GitHub Releases](https://github.com/LanRhyme/ReveriePaint/releases) — 官方构建
- [Mirror 酱](https://mirrorchyan.com/zh/projects?rid=ReveriePaint&os=android) — 国内 CDN 加速

![GitHub Releases 下载入口](/docs/doc-install-repo.webp)

每个版本提供两个架构包：`arm64-v8a` 体积小、性能好，绝大多数的平板与手机装这个；只有在 32 位设备上安装失败时再换 `armeabi-v7a`。

![Releases 安装包列表](/docs/doc-install-release.webp)

::: tip 覆盖安装
新版本可以直接覆盖安装，工程、笔刷、偏好设置都在应用私有目录，不会被替换掉。跨大版本升级时建议先在设置里做一次备份（见 [工程与备份](/guide/project)）。
:::

## 第一次作画

### 1. 新建画布

打开应用是画廊页，点底部中间的 **＋**。

![新建画布](/docs/doc-create.webp)

左侧是系统预设（当前设备全屏、方形 2K/4K、4K UHD、A4 印刷等），右侧能改尺寸、分辨率（DPI）、横竖方向。

| 预设 | 适用 |
| :--- | :--- |
| 当前设备全屏 | 尺寸正好铺满屏幕，适合随手涂 |
| 方形 2048 / 4096 | 头像、插画、社媒配图 |
| 4K UHD（3840×2160） | 横屏场景、概念图 |
| A4 / Letter | 打印输出 |

::: tip 尺寸怎么选
DPI 只影响打印尺寸与笔刷的物理手感参考，不影响像素量。画布像素 = 宽 × 高，**像素越多、可用图层越少**（引擎按内存动态算上限）。不确定就先用「当前设备全屏」或方形 2048。
:::

选好后点右下角「创建画布」，直接进入绘画页。

### 2. 画第一笔

- 用手指或笔在画布上直接画
- 左侧笔刷条点任意笔刷切换
- 右上角两个圆形滑块分别是**笔刷大小**与**不透明度**
- 画错了：**双指轻点**撤销，**三指轻点**重做

### 3. 保存

顶栏 **⚙ → 画布** 里有「保存」与「另存为」；也可以直接点顶栏右上角关闭按钮，退出时会提示保存。

工程默认存为 `.revp`，位置在应用私有目录，也能在设置里指定到公共目录或 WebDAV 云端。

## 常见的第一天问题

| 现象 | 原因与处理 |
| :--- | :--- |
| 手指一碰就画，想用手势 | 打开「仅手写笔模式」：设置 → 手写笔 → 笔模式，之后手指只负责双指缩放与平移 |
| 画面糊、边缘有锯齿 | 画布放大后属正常；设置 → 显示与色彩里可开关「放大插值」与「像素网格」 |
| 笔画跟不上手 | 设置 → 历史记录与性能 → 渲染调度策略选「极速响应」；低端设备可改「均衡平滑」降温 |
| 装不上 / 闪退 | 先确认架构包是否匹配（见上），仍失败请在 [Issues](https://github.com/LanRhyme/ReveriePaint/issues) 附上应用日志 |

更细的问题见 [常见问题](/guide/faq)。
