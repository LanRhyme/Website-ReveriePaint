# 剪贴蒙版与继承透明度

这两个功能看起来像「同一件事的两种叫法」，其实裁剪范围完全不同。用错就会出现「明明开了蒙版，颜色还是溢到外面」的情况。

## 一句话区分

| | 剪贴蒙版（Clipping Mask） | 继承透明度（Inherit Alpha） |
| :--- | :--- | :--- |
| 裁剪基准 | **紧挨着的下一个图层** | **同组内下方所有图层**的可见像素并集 |
| 是否需要图层组 | 不需要 | **必须**在图层组内 |
| 适合 | 单层附着上色（阴影贴线稿） | 一组元素整体上色（角色立绘分层） |
| 面板图标 | 卡片上的剪贴标记 | `α` |

图层面板顶部的快捷按钮可以在两者之间切换（设置 → 图层 → 「图层顶部快捷为继承透明度」）。

## 剪贴蒙版

在目标图层上开启剪贴蒙版，它只显示在**下方那个图层**的不透明区域内：

- 阴影层开剪贴贴在底色层上 → 涂到外面也会被裁掉
- 想改形状：改下方底色层的像素，上方剪贴层自动跟随
- 剪贴层可以有多个，层层堆叠都贴同一个基底；顺序按图层面板从下到上
- 组内的剪贴只作用于组内相邻层；组本身也可以开剪贴，贴住组外的下一层

::: tip 常见坑
剪贴层和基底之间隔了空图层或没开的图层，就会「失效」—— 剪贴找的是**紧邻的下一个可见图层**。调整顺序后记得确认一下它们的相邻关系。
:::

## 继承透明度

继承透明度的裁剪基准是**同组内下方所有图层的并集**：

```
[组] 角色上色组
  ├── 高光（继承透明度 ✓ + 叠加）
  ├── 阴影（继承透明度 ✓ + 正片叠底）
  └── 底色（不开，负责铺形状）
```

- 阴影和高光怎么涂，都只出现在「底色 + 组内其他下层」画过的区域
- 改底色形状时，上层阴影高光自动跟随收放
- **必须放在组里**：直接放在根目录会向下穿透背景层，等于裁到整张画布，看起来像没生效

::: warning 为什么一定要用组
继承透明度的「下方」是按所属组的子树算的。放根目录时它的下方是背景层和整幅画，裁剪范围就成了整张画布。
:::

## 什么时候用哪个

- 只有两层：**剪贴蒙版**，更直接
- 一整套（底色 + 阴影 + 高光 + 纹理）：**继承透明度**，组内统一裁剪，加减层不用重新连
- 需要同时裁多层但不想分组：可以给每层分别开剪贴，贴同一个基底

## 与 Alpha 锁定的区别

Alpha 锁定锁的是**本图层自己的**透明像素（只能画在已有像素上），不涉及其他层；剪贴与继承透明度是**借别人的形状**。三者经常配合使用：底色层开 Alpha 锁定画暗部，上层开剪贴蒙版画高光。

详见 [Alpha 锁定与图层孤立](/guide/alpha-lock)。
