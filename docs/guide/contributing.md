# 参与文档贡献指南

ReveriePaint 官方文档完全开放开源，任何画师、开发者或热心用户均可零门槛参与勘误与补充

## 方式一：在浏览器中 3 步快速提交 PR（推荐）

无需安装 Git，无需搭建 Node.js 开发环境，直接在网页中即可完成贡献：

1. **跳转源码页面**：在任意文档页面点击底部卡片或右侧侧边栏中的「在 GitHub 编辑此页」按钮
2. **在线编辑内容**：在打开的 GitHub 页面点击右上角的铅笔图标（Edit this file），直接修改 Markdown 文本并使用 Preview 页签实时比对效果
3. **提交提议发起 PR**：在页面底部填写简短的修改说明（例如「修正套索工具快捷键表述」），点击「Propose changes」，随后点选「Create pull request」即可完成提交，维护者审阅后将一键合并上线

## 方式二：使用 Web 版 VS Code 在线编辑

如果你需要同时修改多个文件或进行较大篇幅的排版调整：

- 在任意文档页面点击「Web IDE 在线编写」，或在 GitHub 仓库页面键盘直接轻按句点键（`.`）
- 系统将立即在浏览器内启动完整的 GitHub Web 版 VS Code
- 在左侧文件树中修改 `docs/guide/*.md`，并在源代码管理面板提交变更即可

## 方式三：本地开发与实时预览

如果你习惯在本地使用编辑器，可执行以下命令拉取并运行文档实时热重载服务：

```bash
git clone https://github.com/LanRhyme/Website-ReveriePaint.git
cd Website-ReveriePaint
npm install
npm run dev:docs
```

本地服务启动后，在浏览器访问 `http://localhost:5174/docs/` 即可实时预览修改

## 文档编写与排版约定

为了维持手册专业清爽的阅读质感，请在提交修改时留意以下规范：

- **断句与标点**：正文段落与列表条目严禁使用全角句号，请以自然换行、逗号、分号或列表项替代
- **表情符号限制**：文档正文与标题中严禁夹带 Emoji 表情符号，保持极简技术手册风格
- **配图标准**：如需新增功能界面配图，请优先使用清晰的 WebP 格式放置于 `docs/public/docs/` 目录
- **术语规范**：工具名称与菜单项请遵循官方应用内部现有中英文文案
