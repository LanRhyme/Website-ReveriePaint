# 逐帧动画与洋葱皮

展开底部动画时间轴后，画布即刻进入专业逐帧手绘原画创作状态

## 时间轴控制与关键帧编辑

- **关键帧插入与克隆**：支持一键插入空白关键帧或原位复制现有帧，调节单帧驻留时间适配一拍一、一拍二节奏
- **边缘曝光手柄拉伸**：帧块右侧引入曝光长度直接拖拽拉伸手柄，支持弹性连续调节曝光时长
- **推挤重排（Ripple Reorder）**：长按关键帧可在时间轴上自由推挤换位，附带弹性避让动效
- **极速翻帧比对（Flip Peek）**：长按「上一帧」或「下一帧」按钮约 110ms 即可直接调度渲染进入快速预览比对，手指抬起即时恢复作画状态

## 透光台临时位移比对（Shift & Trace）

引入动画工业界经典 Shift & Trace 临时对位能力，解决复杂运动轨迹与转面弧度的校对难题：

- **手笔职责分流**：手写笔落笔 100% 保持在当前活动帧作画，双指手势（捏合、旋转、平移）自由微调参考帧位移对位
- **洋葱皮透光台**：前续帧默认为朱红色标，后续帧默认为青绿色标，支持线性（Linear）、指数平滑（Smooth）与恒定不透明度（Constant）三档衰减曲线
- **仅关键帧透光过滤**：自动跳过一拍多保持帧，仅透光穿透真实有效关键帧

## 多格式动画与音频导出

- **MP4 高清动画视频**：支持导出无损 1080P / 4K 高帧率动画视频
- **动态 GIF 图像**：自动优化调色板索引，输出轻量高清动图
- **连续 PNG 序列帧**：导出带透明通道的标准序列帧 ZIP 压缩包，方便导入 AE 或剪辑软件二次合成
- **音频轨伴奏导入**：支持加载本地 MP3 / WAV 配乐并在时间轴上方直观呈现声音波形，辅助打击点与口型对齐
