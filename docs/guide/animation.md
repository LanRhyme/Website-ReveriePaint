# 逐帧动画与洋葱皮

ReveriePaint 的动画是**图层即轨道**的逐帧模式：每个位图图层是一条轨道，轨道上放关键帧。展开画布下方的时间轴即进入动画作画状态。

![动画时间轴](/docs/doc-animation.webp)

## 新建动画画布

创建画布时勾选「动画画布」，应用会自动给最上面的可动画图层开启动画通道（索引 0 的背景层不参与），并写入默认帧率。

已有工程也可以随时打开时间轴，把任意图层变成动画轨道。

## 时间轴

| 操作 | 说明 |
| :--- | :--- |
| 新建关键帧 | 在当前帧插入空白关键帧 |
| 克隆关键帧 | 原位复制当前帧内容，做小幅修改时省事 |
| 曝光拉伸 | 拖拽帧块右边缘，调节这一帧持续多久（一拍一、一拍二、一拍三） |
| 推挤重排 | 长按关键帧拖动换位，其余帧自动让位 |
| 翻帧比对 | 长按上一帧/下一帧快速预览，抬手回到作画 |
| 播放控制 | 播放/暂停、帧率、播放范围 |
| 轨道 | 每个图层一行，可单独显隐、静音与锁定 |

## 洋葱皮

- 前续帧默认**朱红**、后续帧默认**青绿**
- 衰减曲线：线性 / 指数平滑 / 恒定不透明度
- **仅关键帧透光**：跳过一拍多里的保持帧，只显示真正画过的关键帧
- 洋葱皮只用于显示，不会画进图层，也不影响导出

### Shift & Trace（临时对位）

复杂转面与运动轨迹校对时用：

- **手写笔始终画在当前帧**
- **双指拖动只移动参考帧的显示位置**，实现「透光台对位」
- 松手后参考帧回到原位，画布内容不受影响

## 前景 / 背景帧

需要固定不动的元素（背景、道具）可以标为前景/背景帧，它们在所有帧上恒定显示，不参与逐帧切换。引擎侧不复制像素，只是图层级的豁免。

## 帧率与时长

- 帧率决定播放速度，与导出时的抽帧密度独立
- 时间轴长度 = 所有轨道关键帧的最大结束帧
- 调整播放范围可以只循环某一段

## 导出

动画导出支持 **GIF / MP4 / ZIP（PNG 序列）**，可设分辨率比例、帧范围与透明背景（MP4 不支持透明）。详见 [导出与回放](/guide/export#导出动画)。
