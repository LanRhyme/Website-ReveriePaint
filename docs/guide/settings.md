# 设置与性能

设置分两处：**绘画页顶栏 `⚙`**（画布相关的即时设置）和**主页齿轮 → 设置**（应用级偏好）。这一页按「你在解决什么问题」来组织。

## 画得不跟手 / 发烫

设置 → 历史记录与性能：

| 选项 | 说明 |
| :--- | :--- |
| **渲染调度策略** | `极速响应`（默认，无节流、功耗最高）/ `均衡平滑`（上限 90fps）/ `节能温控`（上限 50~60fps，合并更多帧） |
| **最大撤销步数** | 步数越多内存占用越高，长画布建议 20~50 步 |

低延迟相关（笔迹预测、前缓冲）默认对**新装用户关闭**，因为个别机型的前缓冲直出会在系统层崩溃。想让笔画更跟手，可在设置 → 手写笔里手动打开「超低延迟笔迹预测」，确认设备稳定后再长期使用。

::: tip 卡顿排查顺序
1. 渲染调度改「极速响应」
2. 关闭不需要的 3D 参考图层
3. 降低抖动修正的平滑距离
4. 检查画布尺寸与图层数是否超设备内存（图层上限会随内存动态计算）
:::

## 手写笔与手势

设置 → 手写笔 / 手势：

- **笔模式**：开启后手指只做手势，不再落笔；笔模式下的单指平移可单独开关
- **按住手势**：双指轻点撤销、三指轻点重做、双指快速内捏复位画布，都可单独关闭
- **长按连续撤销/重做**：关掉后只响应单击，防止手掌误触
- **长按吸色**：拾色灵敏度、取色点偏移、笔模式下是否允许手写笔长按取色
- **三指下滑菜单**：开关与自定义条目（与快捷悬浮条相互独立）
- **返回键行为**：无行为 / 弹出菜单 / 返回；「允许边缘侧滑返回」关闭后全屏排除系统手势
- **界面动效速度**：标准 / 极速（0.1s）/ 关闭

## 显示与色彩

设置 → 显示与色彩：

- **主题**：莫兰迪色板与莫奈动态取色，可选主色调、面板透明度、沉浸模式
- **语言**：跟随系统 / 简体中文 / English / 日本語 / 繁體中文 / 猫猫语
- **放大插值**：开启为双线性平滑，关闭为清晰马赛克
- **像素网格**：超微距放大时显示单像素分界线，像素画必备
- **画布旋转** 与 **旋转吸附**（吸附到正投射角）
- **图层项高度** / **快捷滑块长度**：面板密度

## 效率与辅助

- **快捷滑块**：控制笔刷大小/不透明度（可换成流量）
- **面板固定与自由平移**：把图层与画笔面板固定在画布上拖动
- **图层顶部快捷按钮**：切换为「继承透明度」或「剪贴蒙版」
- **笔刷上限跟随画布**：笔刷最大尺寸自动设为画布长边的 1/2
- **快捷键设置**：外接键盘时自定义按键映射（见 [手势与快捷键](/guide/gestures#外接实体键盘快捷键)）

## 保存与备份

设置 → 通用设置：

- **自动保存**：间隔时间、静默提示、**最近自动保存快照**（可恢复草稿 / 清理备份）
- **快照保留数量**：达到上限淘汰最旧版本
- **退出时提示保存**
- **同步与备份**：WebDAV 云端同步与本地归档（见 [工程、备份与 WebDAV](/guide/project)）

## 创作与版权

- **作者档案**：署名、团队机构、默认版权声明，导出时可选嵌入
- **导出日志**：把运行日志复制到剪贴板，反馈问题时直接粘贴

## 关于与更新

- 启动时自动检查更新、手动检查更新
- 版本信息、项目官网、Mirror 酱高速下载
- 第三方开源许可清单、贡献者鸣谢、赞助入口

## 调试开关（可选）

极少数情况下诊断问题会用到系统属性，普通用户不用管：

```bash
adb shell setprop debug.reverie.landdiag 1     # 首笔诊断日志
adb shell setprop debug.reverie.snapshot 0     # 图层镜像退回旧路径 (排障用)
```

属性写入后需要强制停止应用重启才生效。
