# 导出与回放

画完的图有两种出口：**导出静态图 / 动画**（设置面板的「导出」页），以及**回放**（把作画过程压成延时视频）。

## 导出静态图

入口：顶栏 `⚙ → 导出`。

![导出面板](/docs/doc-export.webp)

| 格式 | 说明 | 是否分层 |
| :--- | :--- | :--- |
| **PNG** | 无损合层，带透明通道，最常用 | 否 |
| **JPEG** | 高质量压缩，体积小、适合分享 | 否 |
| **WebP** | 现代网络格式，压缩率更高、支持透明 | 否 |
| **TIFF** | 出版级无损位图 | 否 |
| **PSD** | Photoshop 分层，保留图层、混合模式与剪裁关系 | 是 |
| **KRA** | Krita 原生工程，保留剪切蒙版与混合模式 | 是 |
| **REVP** | ReveriePaint 原生工程，保留作画耗时与全部图层数据 | 是 |

导出选项：

- **分辨率**：按倍率缩放输出
- **画面质量**：JPEG/WebP 的压缩质量
- **嵌入作者元数据**：把设置 → 作者档案里的署名写进图片元信息

导出后可直接「存入相册」（`Pictures/ReveriePaint`）或用系统分享。

::: tip 选哪个
- 发社交平台：**PNG**（透明）或 **JPEG/WebP**（体积小）
- 交给 PS 继续做：**PSD**
- 备份可编辑工程：**REVP**（原生，信息最全）；要和桌面 Krita 互通则用 **KRA**
:::

## 导出动画

入口同上，切到「动画导出」页。适用于带时间轴的逐帧动画。

| 格式 | 特点 |
| :--- | :--- |
| **GIF** | 兼容性最好，体积大、最多 256 色，无半透明平滑 |
| **MP4** | 体积小、画质好，**不支持透明背景**；宽高会自动取偶数 |
| **ZIP** | 导出 PNG 序列帧打包，方便导入其他软件再处理 |

可设置：分辨率比例、导出帧范围（全部帧 / 自定义起止帧）、是否透明背景（仅 GIF 与 ZIP）。

导出过程有进度与「取消导出」，大尺寸长动画建议先降分辨率试一段。

## 回放（延时摄影）

ReveriePaint 会记录你的作画过程（笔画、图层操作、切笔），在画廊里长按作品卡片选「回放」即可观看，也能导出成延时视频。

![回放页](/docs/doc-replay.webp)

回放页：播放 / 暂停、从头播放、倍速（含自定义倍速）。

导出回放时的选项：

| 选项 | 说明 |
| :--- | :--- |
| 导出格式 | **MP4**（默认，适合分享）/ **GIF** / **ZIP**（帧序列） |
| 缩时时长 | 目标成片时长，工具按此反推抽帧密度 |
| 导出区间 | 全部或按时间范围截取 |
| 输出尺寸 | 分辨率 |
| 显示笔刷光标轨迹 | 在回放里画出笔尖运动圆环 |
| 叠加作者签名水印 | 用作者档案里的署名 |
| 结尾定格 1 秒 | 片尾展示成图 |

只有 GIF 与 MP4 能直接存入系统相册；ZIP 走系统文件保存。

## 常见问题

| 现象 | 原因 |
| :--- | :--- |
| PSD 在 PS 里颜色偏一点 | PSD 的色彩管理信息有限，若画布用了非 sRGB 色彩配置，PS 可能按自己的默认配置解读 |
| 导出的 GIF 出现色带 | GIF 只有 256 色，渐变多的画面建议改用 MP4 |
| MP4 没有透明背景 | 视频编码不支持 alpha，这是格式限制，需要透明请用 GIF/ZIP |
| 回放导出失败 / 无数据 | 回放数据只对开启录制后的作画生成，早期作品或刚新建还没落笔的画布没有回放 |
| 导出很慢 | 大画布 + 多图层 + 高质量 JPEG 都是主要开销，可先降分辨率或换 PNG |
