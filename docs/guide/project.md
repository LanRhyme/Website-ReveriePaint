# 工程、备份与 WebDAV

工程安全靠三层：**自动保存**（平时）→ **快照恢复**（意外）→ **云端同步**（跨设备）。这一页讲清楚这三层各自管什么，出问题时该去哪找。

## `.revp` 工程格式

`.revp` 是 ReveriePaint 的原生工程格式，本质是一个 ZIP 容器：

| 内容 | 说明 |
| :--- | :--- |
| 文档元信息 | 画布尺寸、DPI、色彩空间、图层树（顺序、分组、混合模式、可见性）、动画参数 |
| 逐层 PNG | 每个图层一份无损像素数据，组内层级按目录组织 |
| 回放数据 | `timelapse.bin`：笔画坐标、压感、工具切换等事件流（用于回放与延时摄影） |
| 缩略图 | 画廊里显示的预览 |

**增量保存**：再次保存时，未改动过的图层直接复用上次产物里的 PNG 字节，不重新编码、不重新压缩。所以第一次保存较慢，之后只保存真正改动过的层 —— 大工程反复保存不再是一次全量重写。

## 自动保存与快照

设置 → 通用设置：

| 项 | 作用 |
| :--- | :--- |
| 启用自动保存 | 按间隔在后台静默保存，不打断笔画 |
| 保存时间间隔 | 触发频率 |
| 自动保存轻量提示 | 保存完成后的非阻塞提示 |
| 快照保留数量 | 历史快照上限，超出淘汰最旧的一份 |

快照与正式保存分开存放，互不覆盖。想回到某个历史状态，去 **设置 → 通用设置 → 最近自动保存快照**，挑一个版本恢复或清理。

## 崩溃恢复

应用内置原生异常拦截：图形栈崩溃、系统强杀这类意外发生时，会尽可能把当前状态写入保护快照。

重新打开应用时，画廊首页若出现「检测到未保存的项目快照」横幅，点一下即可恢复到崩溃前的草稿。没有出现横幅说明这次退出是正常路径，工程已保存。

## WebDAV 云同步

支持标准 WebDAV：坚果云、Nextcloud、群晖 NAS 等都可以。

配置：设置 → 同步与备份 → 填写服务器地址、用户名、授权密码。

同步行为：

- **按需上传/拉取**：在画廊里对单个工程操作，不会整库重传
- **增量比对**：只传变化的工程包
- **删除联动（墓碑）**：本地删除的工程会记录墓碑标记，下次同步时清理云端副本，避免被旧版本拉回来
- **冲突处理**：同一工程在两处各自修改时按修改时间保留较新的一份，旧版进入备份目录

::: tip 跨设备接力
在两台设备之间接力前先手动同步一次；同步完成后再打开，避免打开的是旧版本又保存回去。
:::

## 备份与归档

除了 WebDAV，还可以在「同步与备份」里做本地归档：把工程、笔刷、预设、设置打包成压缩包，用于换机迁移或长期存档。导入时按分类选择恢复范围。

## 回放数据

工程的回放数据随工程一起保存，体积很小（只有事件流，不是录屏）。回放与延时摄影导出的细节见 [导出与回放](/guide/export)。
