# 触控手势与快捷操作

画布内置原生硬件级多点手势识别引擎，精准区分单指取色、双指漫游、三指动作与多指回退

## 常用手势快捷清单

| 手势动作 | 触发效果 | 交互行为与细节 |
| :--- | :--- | :--- |
| `双指捏合 / 旋转 / 移动` | 视口平移、缩放与旋转 | 围绕双指几何中心平滑过渡，松手后阻尼保留视角 |
| `双指同时轻点` | 撤销（Undo） | 轻触屏幕瞬时回退上一笔或上一次图层修改 |
| `双指按住不放` | 连续高速撤销 | 按住不放持续向前快速回溯历史记录，直到松手停驻 |
| `三指同时轻点` | 重做（Redo） | 轻触屏幕瞬时恢复刚刚撤销的操作步数 |
| `三指按住不放` | 连续高速重做 | 按住不放持续向后快速恢复历史操作 |
| `三指快速下滑` | 三指快捷菜单（可自定义） | 屏幕中央呼出环绕胶囊菜单，默认剪切 / 拷贝 / 粘贴，内容与顺序可自由编排 |
| `双指快速向内捏合` | 适应屏幕（Pinch to Fit） | 瞬时将画布居中并缩放至最佳满屏可视范围，附带平滑过渡 |
| `单指长按屏幕` | 悬浮动态吸色环 | 呼出垂直防遮挡双环取色盘，支持移动连续采样 |

## 三指下滑快捷菜单（环绕胶囊）

在画布任意区域三指同时向下轻滑，屏幕中央即呼出环形胶囊菜单：动作胶囊自正上方起顺时针环绕排布，正中是「快捷菜单」按钮（点击进入自定义），胶囊之间刻意留白，画面不会被整块遮住。

- **默认动作**：剪切、拷贝、粘贴三项剪贴板操作
- **可编排范围**：快捷动作池里的条目都能加进来 —— 撤销 / 重做、橡皮切换、取色、前后景互换、笔刷尺寸增减、Alpha 锁定、新建图层、复制图层、向下合并、清空图层、视图翻转、视角回正、视图锁定、禁用触控、切换上一工具等
- **自动分页**：每页最多 6 项，超出后底部出现翻页箭头与页码
- **剪贴板状态提示**：菜单底部实时提示当前作用于选区还是整层；当前图层没有可复制像素、图层类型不支持或剪贴板不可用时，对应按钮直接置灰
- **粘贴作用域**：剪贴板仅限当前画作内使用，每次粘贴都会生成一个新图层，方便随时单独挪动或丢弃
- **可整体关闭**：在设置面板中可关闭「三指下滑打开编辑菜单」开关；关闭后三指轻点重做不受影响

### 自定义菜单内容与顺序

点击菜单正中的「快捷菜单」按钮，或在设置面板的三指菜单区块点「自定义三指菜单」，进入编排面板：

- **「已选 / 添加」双标签页**：在添加页点选即加入，在已选页用上下箭头调整顺序、点 `−` 移除
- **草稿式编辑**：所有增删与排序先进草稿，**点「保存」才生效**；直接关闭即放弃本次改动，旋转屏幕不会丢失草稿
- **恢复默认**：一键还原为默认的剪切 / 拷贝 / 粘贴三项
- **至少保留一项**：不允许把菜单清空到零项
- **与快捷悬浮条相互独立**：编排三指菜单不会改动快捷操作悬浮条上的动作，两者各存一份配置

## 单指长按吸色防抖机制

针对手指作画时微小生理抖动容易误触拖动画布的问题，系统引入双重防抖与平滑切换机制：

- **moveSlop 移动阈值保护**：长按触发计时器运转期间，在阈值范围内的轻微位移视为稳态长按，不会中断吸色呼出
- **超时平滑切换抓手平移**：若手指移动距离超出阈值，系统平滑放弃吸色判定，无缝过渡为画布平移漫游，杜绝卡顿与视口突跳
- **防遮挡垂直偏移**：取色圆环自动向上偏移显示在手指或笔尖上方，外环为最新采样色，内环为画笔原色

## 仅手写笔模式与触控隔离

- **仅手写笔绘制**：开启后画布仅接收主动式手写笔笔尖信号，手指仅响应双指缩放与平移，手掌随意贴靠画布作画零误触
- **长按空格抓手平移**：连接键盘长按 Space 键可临时切换为抓手平移模式，松手后瞬时还原至原画笔或橡皮擦

## 外接实体键盘快捷键

| 按键组合 | 功能说明 | 按键组合 | 功能说明 |
| :--- | :--- | :--- | :--- |
| `B` | 切换画笔工具 | `E` | 切换橡皮擦工具 |
| `V` | 切换移动与自由变换 | `L` | 切换自由套索选区 |
| `G` | 切换油漆桶与渐变工具 | `I` | 切换吸管工具 |
| `[` / `]` | 快速缩小 / 放大笔刷尺寸 | `Ctrl + Z` | 撤销（Undo） |
| `Ctrl + Shift + Z` | 重做（Redo） | `Ctrl + C` / `Ctrl + V` | 复制 / 粘贴 |
| `Ctrl + A` | 全选画布 | `Ctrl + D` | 取消当前选区 |
| `Ctrl + I` | 选区反选 / 色彩反相 | `Space（长按）` | 临时抓手平移画布 |
| `H` | 视图水平翻转（只镜像显示） | `R` | 画布顺时针旋转 |

::: tip 翻转快捷键
`H` 触发的是**视图翻转**而非像素翻转，只改变你看画面的方式、不动画布数据，图层再多也是瞬时响应；真正镜像像素的「完全翻转」请到画布面板长按翻转图标（详见 [视图翻转与完全翻转](/guide/interface#视图翻转与完全翻转)）。
:::
