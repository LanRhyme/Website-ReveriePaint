# 触控手势与快捷操作

画布内置原生硬件级多点手势识别引擎，精准区分单指取色、双指漫游、三指动作与多指回退

## 常用手势快捷清单

| 手势动作 | 触发效果 | 交互行为与细节 |
| :--- | :--- | :--- |
| `双指捏合 / 旋转 / 移动` | 视口平移、缩放与旋转 | 围绕双指几何中心平滑过渡，松手后阻尼保留视角 |
| `双指同时轻点` | 撤销（Undo） | 轻触屏幕瞬时回退上一笔或上一次图层修改 |
| `双指按住不放` | 连续高速撤销 | 按住不放持续向前快速回溯历史记录，直到松手停驻 |
| `三指同时轻点` | 重做（Redo） | 轻触屏幕瞬时恢复刚刚撤销的操作步数 |
| `三指按住不放` | 连续高速重做 | 按住不放持续向后快速恢复历史操作 |
| `三指快速下滑` | 三指编辑浮动菜单 | 在屏幕触点下方呼出包含剪切、拷贝、复制、清除与向下合并的浮动面板 |
| `双指快速向内捏合` | 适应屏幕（Pinch to Fit） | 瞬时将画布居中并缩放至最佳满屏可视范围，附带平滑过渡 |
| `单指长按屏幕` | 悬浮动态吸色环 | 呼出垂直防遮挡双环取色盘，支持移动连续采样 |

## 三指编辑浮动菜单

在画布任意区域三指同时向下轻滑，即可在指尖位置即时呼出编辑命令条：

- **剪切（Cut）**：将当前选区或当前图层内容移入剪贴板并清空源选区
- **拷贝（Copy）**：提取选区内像素写入剪贴板，支持跨工程与跨图层粘贴
- **复制图层（Duplicate）**：在当前图层上方原位克隆副本
- **清空图层（Clear）**：清空图层内全部像素（或活动选区内的像素）
- **向下合并（Merge Down）**：将当前活动图层与下方相邻图层合并为一个栅格图层

## 单指长按吸色防抖机制

针对手指作画时微小生理抖动容易误触拖动画布的问题，系统引入双重防抖与平滑切换机制：

- **moveSlop 移动阈值保护**：长按触发计时器运转期间，在阈值范围内的轻微位移视为稳态长按，不会中断吸色呼出
- **超时平滑切换抓手平移**：若手指移动距离超出阈值，系统平滑放弃吸色判定，无缝过渡为画布平移漫游，杜绝卡顿与视口突跳
- **防遮挡垂直偏移**：取色圆环自动向上偏移显示在手指或笔尖上方，外环为最新采样色，内环为画笔原色

## 仅手写笔模式与触控隔离

- **仅手写笔绘制**：开启后画布仅接收主动式手写笔笔尖信号，手指仅响应双指缩放与平移，手掌随意贴靠画布作画零误触
- **长按空格抓手平移**：连接键盘长按 Space 键可临时切换为抓手平移模式，松手后瞬时还原至原画笔或橡皮擦

## 外接实体键盘快捷键

| 按键组合 | 功能说明 | 按键组合 | 功能说明 |
| :--- | :--- | :--- | :--- |
| `B` | 切换画笔工具 | `E` | 切换橡皮擦工具 |
| `V` | 切换移动与自由变换 | `L` | 切换自由套索选区 |
| `G` | 切换油漆桶与渐变工具 | `I` | 切换吸管工具 |
| `[` / `]` | 快速缩小 / 放大笔刷尺寸 | `Ctrl + Z` | 撤销（Undo） |
| `Ctrl + Shift + Z` | 重做（Redo） | `Ctrl + C` / `Ctrl + V` | 复制 / 粘贴 |
| `Ctrl + A` | 全选画布 | `Ctrl + D` | 取消当前选区 |
| `Ctrl + I` | 选区反选 / 色彩反相 | `Space（长按）` | 临时抓手平移画布 |
