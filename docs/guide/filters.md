# 35 种滤镜与线稿提取

ReveriePaint 内置完整的 GPU 加速滤镜矩阵，可即时作用于当前图层或配合选区局部生效

## 滤镜分类全集

| 分类维度 | 包含滤镜与底层算法 |
| :--- | :--- |
| **色彩调校（Color）** | HSV 色相/饱和度/明度、RGB/CMYK 曲线（Curves）、色阶（Levels）、自然饱和度（Vibrance）、色彩平衡、色温与色调、阴影与高光、曝光度、去色、反相、二值化阈值 |
| **模糊平滑（Blur）** | 高斯模糊（Gaussian Blur）、运动模糊（Motion Blur）、径向变焦模糊（Radial Blur）、表面平滑保边模糊（Surface Blur）、散焦镜头景深（Defocus） |
| **增强光效（Enhance）** | 泛光辉光（Bloom）、智能锐化（Sharpen）、自适应投影（Drop Shadow）、边缘霓虹发光（Edge Glow）、Sobel 边缘检测、浮雕质感（Emboss） |
| **通道映射（Map）** | 渐变映射（Gradient Map）、亮度转 Alpha（提取线稿）、颜色转 Alpha（一键抠底）、亮度转不透明度 |
| **艺术与扭曲（Art & Distort）** | 半色调印刷网点（Halftone）、马赛克（Mosaic）、数字油画（Oil）、高斯噪点（Noise）、扫描线（Scanline）、故障艺术（Glitch）、水波纹（Ripple）、旋涡（Swirl） |

## 高频核心滤镜实战

### 亮度转 Alpha（提取手绘线稿）

在现实纸张上手绘草稿后，使用平板相机拍照导入工程：
1. 选中手绘照片所在图层
2. 打开滤镜菜单，选择「通道映射 ＞ 亮度转 Alpha」
3. 系统将瞬时将纯白与浅灰底色完全转化为透明通道，完整保留黑色手绘铅笔质感与线条细节，省去繁琐的人工抠图

### 渐变映射（素描黑白稿一键叠色）

插画厚涂工作流中的着色利器：
- 绘制完成黑白明暗灰阶素描后，应用渐变映射滤镜
- 通过在渐变条上添加深红、暖黄、高光冷白等色标，系统将自动把灰度明度值映射为对应阶梯色彩，快速铺陈全局气氛

### 泛光辉光（Bloom）

模拟相机大光圈与空气粉尘对高亮光源的散射光晕，为角色眼眸闪烁、法术光环与日落逆光注入通透的空气感
