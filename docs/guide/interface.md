# 主界面与工具栏定制

ReveriePaint 采用针对触控屏幕优化的沉浸式全屏工作区，提供极具弹性的工具栏与悬浮面板布局定制

![主界面工作区总览](/docs/doc-ui-main.webp)

## 快捷悬浮面板与快捷操作条

为了提升高频操作效率，系统引入可停靠、可自由拖拽的快捷悬浮组件：

- **快捷笔刷悬浮面板**：常驻当前收藏与高频画笔，支持点击快速切笔，长按可进入编辑模式拖拽重排
- **快捷操作自定义悬浮条**：可吸附于画布边缘或任意空白区域，自由配置常用动作插槽
  - 视图翻转·横 / 视图翻转·纵（View Flip，只镜像显示）
  - 一键居中回正（Fit & Reset View）
  - 图层面板快速呼出（Toggle Layers Panel）
  - 选区与反选切换（Invert Selection）
  - 清空当前图层（Clear Layer）
- **长按排序交互**：长按快捷条图标出现轻微微触觉振动，即可自由调整前后顺序或移除动作

## 视图翻转与完全翻转

「翻转画布」被拆成了两种语义完全不同的操作，分别服务于「临时看一下」和「真的改画面」：

| 对比项 | 视图翻转（View Flip） | 完全翻转（Full Flip） |
| :--- | :--- | :--- |
| 作用对象 | 只镜像**显示**，一个像素都不改 | 逐层镜像每个可绘制图层的像素 |
| 开销 | 零开销，图层再多也是瞬时切换 | 需要重绘每一层，图层多时明显耗时 |
| 撤销栈 | 不进撤销栈 | 打包为**单个**合成撤销步，一次撤销即可回退 |
| 导出与回放 | 不影响导出结果，也不录入延时摄影 | 真实改动画面，会被录制 |
| 典型用途 | 检查构图平衡、对照着画几笔、随时切回 | 定稿后确定要把画面镜像过来 |

### 触发方式一览

入口统一为三处：设置面板「画布」页「变换与调整」分组里的「水平翻转 / 垂直翻转」图标、快捷操作悬浮条、以及键盘与快捷指令。

| 入口 | 交互 | 结果 |
| :--- | :--- | :--- |
| 设置面板 → 画布 → 变换与调整 → 水平 / 垂直翻转 | **单击** | 视图翻转（图标在该轴处于翻转态时高亮） |
| 设置面板 → 画布 → 变换与调整 → 水平 / 垂直翻转 | **长按** | 完全翻转，并同时把该轴的视图翻转复位 |
| 快捷操作悬浮条的「视图翻转·横 / 纵」 | 点击 | 视图翻转，在「未翻转 / 已翻转」两种高亮态间切换 |
| 外接键盘 `H` / 快捷指令「视图水平翻转」 | 触发 | 视图翻转（水平） |

长按做完全翻转时会把视图翻转一并复位，否则两次镜像叠在一起、画面看起来「翻了没变化」。完全翻转没有默认快捷键，避免误触改到像素。

### 以当前视图中心为轴

视图翻转绕的是**屏幕当前视图的中心**，而不是画布中心：翻转前后视图中心看到的始终是同一处内容，翻完不用再把画布拖回去找刚才在画的位置。画布带旋转时同样成立 —— 镜像轴随之旋转，不会把画面甩到对角。反复来回切换也不会累积偏移。

::: warning 作画时的读法
视图翻转下笔触落点、选区与取色都跟随镜像后的画面，「看到哪就画到哪」始终成立；测量工具的读数这类界面标注不会跟着镜像，保持正向可读。而文字工具的预览属于画面内容，会跟随镜像 —— 它预示的正是提交后写进图层的样子。
:::

## 画布视图锁定与辅助

在顶栏或手势设置中可对视口手势进行精细化锁定：

- **独立缩放锁（Zoom Lock）**：锁定后双指缩放操作不再改变画布放大比例，仅允许双指平移与漫游
- **独立旋转锁（Rotation Lock）**：锁定后双指旋转手势失效，彻底防止双指漫游作画时画布出现细微倾斜
- **像素网格（Pixel Grid）**：超微距放大画布超过 1600% 时自动显现单像素分界线，适配像素画精修
- **放大插值平滑**：开启时放大呈现双线性平滑插值，关闭时呈现清晰马赛克锐利边缘
- **快捷侧滑块（Quick Sliders）**：常驻控制笔刷尺寸与不透明度，支持单滑块或双滑块并排展开

## 左手模式与边缘防误触

针对大屏平板作画时的手掌贴靠与系统手势冲突进行了底层加固：

- **全界面镜像停靠**：在偏好设置中开启左手模式后，工具栏、快捷滑块、顶栏以及全部浮动面板自适应镜像至屏幕右侧
- **系统边缘手势动态排除**：基于 Android 系统 API 动态全高度排除左右边缘返回手势区域，彻底杜绝在画布边缘起笔时误触发系统返回桌面或退出的情况
- **边缘动态缓冲区**：在屏幕边缘运笔时自动启用动态坐标阻尼滤波，防止边缘触控采样跳跃
